# 《搜索》Android 项目（0.3.0）

这是一个可在 Android Studio / GitHub Actions 中构建的原生 Kotlin Android 项目。它不是已经编译好的 APK。

## 当前功能
- 应用名称：搜索；黑色主色、红色强调色。
- 全部、商品、新闻、网站、图片类别入口。
- DuckDuckGo、Bing、Google 搜索引擎切换。
- 尝试将搜索页通过 Google 翻译入口转为简体中文；翻译不支持或失败时可关闭开关查看原文。
- 网络搜索，无需应用内账号；手机需有网络连接。
- 最低 Android API 26（Android 8.0）。

## 生成可安装 APK（不需要在手机上安装编译工具）
1. 在 GitHub 新建一个空仓库。
2. 将 ZIP 解压，把其中所有文件（包括隐藏的 `.github` 文件夹）上传到仓库根目录。
3. 打开仓库的 **Actions** 页面，选择 **Build Search APK**，点击 **Run workflow**。首次上传到 `main`/`master` 分支也会自动触发构建。
4. 等待工作流完成并显示绿色成功标记。
5. 打开该次运行详情，在 **Artifacts** 下载 `sousuo-android-apk`，解压后得到 `app-debug.apk`。
6. 把 APK 传到安卓手机，点击安装。若系统提示，允许你使用的文件管理器或浏览器“安装未知应用”。

## 功能边界
- 当前结果来自所选的第三方搜索引擎，本项目不是自建的全球搜索引擎，也没有自己的全球爬虫/网页索引服务器。
- 自动翻译通过第三方翻译网页尝试实现，受网站、网络和地区可用性影响；并非保证逐条结果或所有网页都能翻译。
- 不内置 VPN/加速器。不能保证所有国家/网络都可直连所有搜索网站。
- Debug APK 用于课程和测试，不是正式商店发布版本。安装来源提示属于 Android 系统安全机制。
